# Homebrew MajiMac

This is the custom Homebrew tap for [MajiMac](https://github.com/majimawrks/majimac), a sleek macOS utility for RAR extraction and PDF merging.

## Installation

You can install MajiMac via Homebrew by adding this tap and installing the cask:

```bash
brew tap majimawrks/majimac
brew install --cask majimac
```
